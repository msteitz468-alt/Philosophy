# Cognitive Package Deal (Clark)
> Perception, imagination, understanding, memory, and dreaming are not separate faculties bolted onto a seeing-machine. They are variant uses of the same top-down generative model.

## Summary

Chapter 3 of *Surfing Uncertainty* names this thesis twice. Opening: "Perception, imagination, understanding, and memory come as a kind of cognitive package deal" (3.1). Closing: "PP offers an attractive 'cognitive package deal' in which perception, understanding, dreaming, memory, and imagination may all emerge as variant expressions of the same underlying mechanistic ploy" (3.12). The preface already had the thought: meat that predicts is imagining and dreaming meat, because the connections that match incoming data can also be driven from the top down.

The mechanism is simple once [[Concepts/Predictive Processing (Clark)]] is in place. Online perception meets the sensory stream with multilevel predictions. Run the same machinery with the usual sensory flow down-weighted (low sensory precision) and you get imagery, dreams, and "mental time travel." There is "a deep duality between online perception… and capacities for the endogenous generation of quasi-sensory states" (3.7). Animals that perceive hidden causes can generate sensory-like states for themselves. Deliberate imagery may need language; the capacity itself does not.

This is why Clark treats construction effects as perception, not late memory add-ons: Cornsweet, cross- and meta-modal effects (VWFA for Braille; handwriting across effectors), and **omissions** — expected-but-absent events produce prediction error, and a dim illusory onset, with *no* sensory input. Memory is reconstructive because the organ is prospective (Schacter). Dreams sequester internal dynamics from the sensorium (Hobson & Friston AIM: amines/cholines as precision-gating) and prune complexity.

The 2023 popularization folds this into [[Concepts/Controlled Hallucination (Clark)]] and [[Concepts/Hacking the Prediction Machine (Clark)]]. The 2016 name is the package deal, and it is load-bearing: it is how a prediction machine gets imagination and off-line reason "for free" once it can perceive.

## Key Claims / Positions

- **Same ploy, different precision regime.** Imagery and perception share fine-grained ventral-temporal codes (Reddy et al.); early visual cortex joins only when task grain and precision demand it.
- **Omissions prove the generative model.** A missing expected note is as perceptually salient as a sound. Residual error does not require residual input.
- **Dreams are sequestered prediction.** Low sensory precision; no hypothesis-checking action; sleep as complexity-reducing pruning.
- **PIMMS.** Hippocampus–perirhinal–occipito-temporal mutual prediction (item↔context) for recollection vs familiarity.
- **Incomplete until embodied.** Ch 3 ends by saying the picture is unfinished until prediction is nested in body, culture, and technology (Parts II–III). The package deal is the *inner* half of [[Concepts/Action-Oriented Engagement Machine (Clark)]].

## How This Relates to Prior Thinkers

- **[[Thinkers/Daniel Dennett]]**: SLICE already said that commanding a generative model *is* understanding. The package deal is that claim extended: the same model, run off-line, is imagination.
- **[[Thinkers/Anil Seth]]**: later splits "predictive processing" (mechanism) from "controlled hallucination" (phenomenology). Clark 2016's package deal is the mechanism-level version of that split — imagery and perception as one organ — without Seth's later owner-story for the slogan.
- **[[Thinkers/Jakob Hohwy]]**: 2013 already has generative "fantasy" of expected input. Hohwy does not package imagination, dreaming, and memory as co-emergent in the same way; his book is scoped to perception.
- **[[Concepts/Multiple Drafts Model (Dennett)]]**: no inner screen on which a finished percept is displayed, then copied into imagination. Both are drafts of the same generative cascade.

## Contradictions / Open Questions

- Ch 3 treats "controlled hallucination" as a catchy and "potentially a little distortive" slogan, deferred to Ch 6. The package deal does *not* already say that what we perceive is a hallucination.
- Lucky confabulation ≠ perception: Clark requires counterfactual tracking plus attention-gain on error (3.6).
